Development Prototype

OS Custom

Custom x86-64 operating-system project: BIOS boot chain, long-mode kernel, firmware interfaces, hardware discovery and compatibility layers.

View source on GitHub →

Architecture

BIOS Boot

Stage 1 loads the second stage, which loads the kernel and transitions into 64-bit long mode.

Kernel

Native x86-64 kernel skeleton with a linker layout and explicit subsystem entry points.

Hardware

Planned CPU, PCI, storage, network, GPU and NUMA interfaces.

Compatibility

Compatibility work is organized as API/emulation layers rather than replacing the native kernel.

Build

sudo apt-get install nasm binutils make python3 qemu-system-x86
make clean
make check
qemu-system-x86_64 -drive format=raw,file=build/os-custom.img -m 256M

Status

The repository has a reproducible CI build and structural image validation. It remains an educational/development OS prototype; filesystem, user mode, security boundaries, complete interrupt handling and production hardware drivers are still under development.
